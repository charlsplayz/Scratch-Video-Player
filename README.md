# Scratch-Video-Player
A simple Video Player built inside Turbowarp.

## How to use
### Loading Local Files
When Loading in, Press the Green Flag to Load all the required code.
Then, you can use the menu bar to load a video or an audio file.

### Loading YouTube Videos
Select the [Open YouTube Video...] button, then enter either a `youtube.com/watch?v=` link or a `youtu.be` link.

### Searching for Lyrics
Click on the Lyrics button, then enter in the Song Name, then if you know the artist, enter it. Otherwise, leave it blank.
Then, a list of songs will show up, with the song name, artist, and duration.
Use the number index to select one, then it will sync the lyrics to the currect audio file.
